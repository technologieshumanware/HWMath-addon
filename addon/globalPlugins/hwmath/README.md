# HWMath Introduction

HWMath is an NVDA add-on that enables the display in Braille and speech of mathematical content written in MathML.
MathML is the standard language for describing math content on the web, which enables visually readable math content through a web browser. MathML is also now the preferred way to represent math in Microsoft Word.

HWMath leverages the advances made in mainstream web tools like MathJAX. 
HWMath also uses the mathml2braille javascript library

## HWMath settings
* Braille code for math : Nemeth | UEB | French 
* Selection of an external executable for interaction.

##  Interaction Features Overview
* Allows passing the mathml content to a designated external program for further interaction. 
For example, passing that content to a graphing calculator like HumanWare's KeyMath.

## Main usages
Reading content featuring math expressions on the web 
Tested with Chrome, Edge


Reading content featuring math expressions in word documents
A change in an advanced setting in NVDA to set UI Automation for Word to Always seems to allow reliable detection
